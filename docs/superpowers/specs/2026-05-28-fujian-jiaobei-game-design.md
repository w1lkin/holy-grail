# 福建圣杯掷筊小游戏 — 设计规格 v2

## 概述

一款面向微信环境的 HTML 掷筊小游戏。核心玩法：连续掷筊博取圣杯连击，用户在"继续冒险"和"见好就收"之间博弈，点击 STOP 结算保存战绩与解读。视觉风格为都市牛马风（打工人自嘲美学），办公室日常元素+反讽幽默。

## 游戏流程

```
输入问题(可选) → 上滑掷杯 → 结果揭晓 → 圣杯？连击+1 : 连击中断
                                    ↓
                            继续掷 / 点击 STOP
                                    ↓
                            STOP → 结算保存 → 展示解读
                                    ↓
                            连击达⑨ → 强制暴击停止 → 天神级结算
```

### 详细流程

1. **初始状态** — 可选输入占卜事项（文本输入框），不输入也可直接掷。屏幕中央一双大筊杯（占屏幕至少一半），提示"上滑或点击掷筊"
2. **掷杯动作** — 手指上滑或点击筊杯触发，筊杯旋转飞出（约 1-1.5 秒），动画结束后揭晓结果
3. **结果展示** — 圣杯（一正一反）/笑杯（两正）/阴杯（两反）
   - 圣杯：连击计数 +1，特效随连击数升级
   - 笑杯/阴杯：连击归零，可继续掷或 STOP 结算
4. **STOP 按钮始终可见** — 用户任何时候点击 → 结算本次战绩 → 生成解读 → 保存记录
5. **九连暴击** — 连续 9 次圣杯，触发全屏天神降临特效，强制停止，最高荣誉结算

## 视觉风格 — 都市牛马风（打工人自嘲美学）

- **主色调**：办公室灰白 (#f5f5f0) 底色、文件柜米 (#e8e0d5)、荧光灯白 (#fafaf5)
- **强调色**：Excel绿 (#217346)、咖啡棕 (#6f4e37)、审批红 (#c41e3a)、加班蓝 (#1d3557)
- **筊杯造型**：CSS 绘制成两个键盘按键/回车键风格，或咖啡杯俯视图
- **UI 元素**：便签纸卡片、Excel 表格线框、打卡机数字、工位隔板分区、审批章
- **字体**：系统默认，标题可用等宽/打印体增强办公感
- **氛围**：工位 + 咖啡续命 + 打工人的玄学时刻，讽刺中带着温暖
- **幽默基调**：把"圣杯"包装成"今日宜请假/宜摸鱼"，"阴杯"包装成"加班预警/需求变更"

## 交互 — 上滑/点击掷杯 + 手动停止

- **掷杯手势**：`touchstart → touchend`，上滑超过 60px 触发；或直接点击筊杯触发
- **STOP 按钮**：全局可见，点击结算
- **动画期间锁定**：掷杯翻转动画中阻止再次触发，动画结束后解锁
- **连续掷杯**：每次动画结束→筊杯复位→可继续掷或点 STOP

## 筊杯设计

- **尺寸**：大尺寸，占屏幕至少一半（约 100x150px 起步）
- **造型**：光滑月牙形，金色渐变+辉光阴影，可加轻微内阴影增加立体感
- **动画**：上抛翻转 720°，落地弹性动画

## 结果与概率

| 结果 | 条件 | 概率 | 效果 |
|------|------|------|------|
| 圣杯 | 一正一反 | ~65-70% | 连击+1，特效升级 |
| 笑杯 | 两弧面朝上 | ~15-18% | 连击归零，可继续/STOP |
| 阴杯 | 两平面朝上 | ~15-18% | 连击归零，可继续/STOP |

每次掷杯的结果在滑抛动作触发时即刻随机决定，动画仅为视觉包装。

## 连击系统 — 里程碑式提示

不使用常驻进度条，改用里程碑式浮动提示（toast），在关键节点弹出：

| 连击数 | 里程碑 | 提示样式 |
|--------|--------|----------|
| x1-2 | - | 无特殊提示，筊杯微光 |
| x3 | 🔥 三连击！ | 审批章"通过"戳印 toast，2秒后消失 |
| x6 | ⚡ 六连击！ | 屏幕边缘震动 + 金币粒子 + toast |
| x9 | 🌟 九连暴击！ | 全屏"升职加薪"动画，强制 STOP，不可继续 |

- 笑杯/阴杯 → 连击计数器归零，特效重置
- 里程碑 toast 从屏幕上方飘入，短暂停留后消失，不打断游戏

## 解读系统

结算时根据最终战绩生成解读文字：

- 解读因子：最高连击数、总圣杯数、总掷杯数、用户输入的问题
- 解读为预设文本池匹配，非 AI 生成
- 文本池分为四档：凶（低圣杯率）/ 平 / 吉（高圣杯率）/ 大吉（9连暴击）
- 解读内容以打工人职场梗为主：短句+运势提示，反讽幽默
- **如果用户填写了问题，解读需呼应问题内容**（例如问"该不该跳槽？" → 解读中提及"跳槽""裸辞"等关键词）

### 解读档位示例

| 档位 | 条件 | 标签 | 风格 |
|------|------|------|------|
| 大吉 | 9连暴击 | 🏆 带薪年假 | "九天连圣！老板看了都沉默，今日宜提涨薪、宜早退、宜一切。" |
| 吉 | 圣杯率≥70% | ☕ 宜摸鱼 | "运势走高，今日提案过审概率大。建议趁机提需求。" |
| 平 | 圣杯率40-70% | 📋 需求评审中 | "运势平平，需求可能变更，建议原地待命不要冲动。" |
| 凶 | 圣杯率<40% | ⚠️ 加班预警 | "今日诸事不宜，会议改期、代码回滚、下班早点走。" |

## 保存记录

每次 STOP 结算后自动保存到 localStorage：

```js
{
  id: timestamp,
  date: "2026-05-28 15:42",
  question: "这次考试能过吗？",        // 用户输入的问题（可为空）
  results: ["shengbei","shengbei","xiaobei","shengbei",...],  // 本次所有掷杯结果
  maxCombo: 3,                         // 最高连击
  totalThrows: 7,                      // 总掷杯次数
  shengbeiCount: 5,                    // 圣杯次数
  tier: "ji",                          // 解读档位
  interpretation: "神明眷顾，所愿可成。保持信心前行。"
}
```

- 主界面展示历史记录摘要列表（最近 20 条）
- 点击可展开查看完整详情

## 分享功能

结算面板中提供"分享战绩"按钮：
- Canvas 绘制分享图：工位便签纸背景 + 战绩数据 + 解读文字 + 装饰元素
- 底部预留 QR 占位区域
- 导出为 `<img>` 展示，提示用户长按保存或发送给朋友

## 技术架构

- **单文件 HTML**，内嵌 CSS + JS，零依赖
- 使用 CSS 变量管理配色主题
- Canvas 用于分享图生成和粒子特效
- `localStorage` 存储历史和统计

### 性能要求

- 页面加载 < 2 秒
- 动画 60fps，粒子特效需控制数量（< 50 个粒子同时存在）

## 不做的

- 不求签不解签（保留后续）
- 不接入微信 JS-SDK
- 不做音效
- 不做多语言
- 不做后端/数据库
- 不做多人在线/排行榜

## 验收标准

1. 输入框可输入占卜事项（可为空），直接掷杯
2. 上滑手势正确触发掷杯动画
3. 圣杯概率明显偏高（~65-70%）
4. 连击计数器正确追踪，笑杯/阴杯正确归零
5. 连击特效分档正确（1-2 / 3-5 / 6-8 / 9 暴击）
6. 9 连暴击强制停止，全屏特效
7. STOP 按钮随时可用，点击后结算保存
8. 解读根据战绩正确分档
9. localStorage 正确保存每次结算记录
10. 分享 Canvas 图可正常生成
